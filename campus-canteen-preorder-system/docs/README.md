# SE-01 lab and design record

This folder contains the editable working material for all 12 Software Engineering experiments for **SE-01 Campus Canteen Pre-Order System**. The same scope is used by the Flask/SQLite application in the project root.

The Word lab record is built from the supplied university template. Keep its student/team details and supplied Experiment 1 text intact. Lab dates, marks, faculty remarks/signatures, and fieldwork evidence remain blank until completed by the team and instructor.

The `.mmd` diagrams are Mermaid source files and can be edited in any Mermaid-compatible editor. The experiment notes link to each diagram. Planned estimates and the worked EVA example are explicitly marked as planning assumptions. No interview, observation, usability result, or faculty sign-off is asserted without evidence.
